# Python 콘솔 퀴즈 게임 (CLI Quiz Game)

## 1. 프로젝트 개요
* Python 기반의 콘솔 CLI 퀴즈 게임 프로그램입니다.
* `state.json` 파일 입출력을 통해 프로그램 종료 후에도 추가된 퀴즈와 최고 점수가 안전하게 유지됩니다.
* 공통 입력 검증(공백, 비숫자, 범위 밖 숫자) 및 `KeyboardInterrupt`(Ctrl+C), 파일 손상 등 예외 상황에 유연하게 대응합니다.

## 2. 퀴즈 주제 및 선정 이유
* **주제**: Python 핵심 문법 및 객체지향 기초
* **선정 이유**: Python 기본 개념을 복습하고, 객체지향 구조화와 JSON 데이터 직렬화/역직렬화 및 예외 처리 로직을 실전적으로 검증하기 위해 선정하였습니다.

## 3. 실행 방법
프로젝트 루트 디렉터리에서 아래 명령어를 실행합니다.

```bash
python main.py
```

## 4. 주요 기능

| 기능 | 주요 역할 및 세부 동작 |
| :--- | :--- |
| **퀴즈 풀기** | 저장된 퀴즈를 순차 출제하고 정답 여부를 판정합니다. 풀이 완료 후 최종 점수를 계산하며, 최고 점수 달성 시 자동으로 갱신 및 저장합니다. |
| **퀴즈 추가** | 문제 내용, 선택지 4개, 정답 번호(1~4)를 입력받아 새로운 퀴즈를 등록하고 `state.json` 파일에 즉시 보존합니다. |
| **퀴즈 목록** | 현재 저장되어 있는 전체 퀴즈 목록과 각 문제의 선택지, 정답 번호를 한눈에 조회합니다. |
| **최고 점수 확인** | 현재까지 기록된 최고 점수를 확인합니다. (기록이 없을 경우 안내 문구 출력) |
| **데이터 복구 및 안전성** | `state.json` 파일 부재 또는 손상 시 기본 퀴즈 데이터셋으로 자동 초기화/복구하여 예외 발생 시에도 안전하게 실행을 유지합니다. |

## 5. 파일 구조 

```bash
python_quiz/
├── main.py          # 프로그램 진입점 (Entry point)
├── quiz.py          # Quiz(도메인 모델)클래스
├── quiz_game.py     # QuizGame(제어/저장소) 클래스
├── state.json       # 동적 상태 데이터 (Git 미추적)
├── .gitignore       # Python 캐시 및 state.json 추적 제외 설정
└── README.md        # 프로젝트 명세서
```

## 6. 데이터 파일 (`state.json`)

* **파일 경로**: 프로젝트 루트 (`./state.json`)
* **역할**: 퀴즈 데이터셋과 최고 점수 기록의 영속성 보존 (UTF-8 인코딩)
* **필드 구성**:

| 필드명 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | List | 퀴즈 객체 목록 |
| `quizzes[].question` | String | 퀴즈 문제 내용 |
| `quizzes[].choices` | List[String] | 선택지 4개 리스트 |
| `quizzes[].answer` | Integer | 정답 번호 (`1`~`4`) |
| `best_score` | Integer | 현재까지 기록된 최고 점수 |
---
### JSON 구조 예시

```json
{
  "quizzes": [
    {
      "question": "노르웨이의 수도는?",
      "choices": [
        "오슬로",
        "트롬쇠",
        "릴해머",
        "베르겐"
      ],
      "answer": 1
    }
  ],
  "best_score": 6
}
```


### 7. 핵심 클래스 구조 명세

**Quiz 클래스 (`quiz.py`)**

| 구분 | 이름 | 역할 및 기능 |
| --- | --- | --- |
| **속성** | `question` | 퀴즈 문제 내용 문구 |
| **속성** | `choices` | 선택지 4개 리스트 (생성 시 정규식으로 중복 번호 자동 정화) |
| **속성** | `answer` | 정답 번호 (`1`~`4`) |
| **메서드** | `sanitize_text(text)` | 정규식(`^\s*(\d+[\.\)]\s*)+`)을 이용해 선택지 앞부분의 중복 번호 제거 |
| **메서드** | `is_correct(user_choice)` | 사용자 입력 번호와 정답 비교 (`True`/`False`) |
| **메서드** | `to_dict()` | JSON 저장을 위해 객체 속성을 딕셔너리(`dict`)로 변환 |
| **메서드** | `from_dict(data)` | 딕셔너리 데이터로부터 `Quiz` 객체를 생성하는 클래스 메서드 |

**QuizGame 클래스 (`quiz_game.py`)**

| 구분 | 이름 | 역할 및 기능 |
| --- | --- | --- |
| **속성** | `quizzes` | 현재 로드된 전체 `Quiz` 객체 리스트 |
| **속성** | `best_score` | 현재까지 기록된 최고 점수 |
| **메서드** | `load_state()` | `state.json` 파일에서 데이터 복원 (부재/손상 시 기본값 복구) |
| **메서드** | `save_state()` | 현재 퀴즈 목록과 최고 점수를 `state.json`에 저장 |
| **메서드** | `display_menu()` | 메인 메뉴 화면 출력 |
| **메서드** | `get_valid_input(prompt, min, max)` | 공백, 비숫자, 범위 밖 입력을 처리하는 공통 검증 메서드 |
| **메서드** | `run()` | 메인 게임 루프 및 `KeyboardInterrupt`(Ctrl+C) 예외 처리 |
| **메서드** | `play_quiz()` | 1번 메뉴: 퀴즈 출제, 정답 검증 및 최고 점수 자동 갱신 |
| **메서드** | `add_quiz()` | 2번 메뉴: 사용자 입력을 받아 새 퀴즈 추가 및 파일 저장 |
| **메서드** | `show_quiz_list()` | 3번 메뉴: 전체 퀴즈 목록과 정답 출력 |
| **메서드** | `show_best_score()` | 4번 메뉴: 현재 기록된 최고 점수 출력 |
